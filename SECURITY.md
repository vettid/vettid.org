# Security Policy

**Please do not file public GitHub issues for security findings.**

Report vulnerabilities to **security@vettid.org** — encrypt with the PGP key
published at [vettid.org/security](https://vettid.org/security) (fingerprint
`E23A 83D6 7828 2CD7 9E95 E5F7 1523 8C03 B404 DAEB`) if your report contains
exploit details.

The full disclosure policy — scope, severity targets, response timelines, and
safe harbor — lives at [vettid.org/security](https://vettid.org/security) and
[vettid.org/.well-known/security.txt](https://vettid.org/.well-known/security.txt).

Acknowledgement target: 72 hours.
