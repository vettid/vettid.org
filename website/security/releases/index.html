Vault release log

Every vault release VettID runs: what it is, what changed, and how long it keeps running.

Releases

No production release has been published yet. The first release appears here, and in the signed manifest, when the vault opens to members.

How to check a release

VettID lists every vault release it runs in a signed manifest at /.well-known/vettid/pcr-manifest.json. Your app verifies its signature with a key built into the app, and your vault only opens in the release you approved. This log is generated from that manifest, so the two cannot disagree; the manifest's history is public in the vettid.org repository.

Releases are built reproducibly from the public vettid-vault source. Anyone can rebuild a release from its tag and compare the measurement (PCR0) with the one listed here: how to rebuild and match.

What the statuses mean, and how long each release keeps running, is explained in Vault release updates: a release is kept for at least 12 months after a newer one replaces it, the last 90 days with a final notice and emails, then it ends.
